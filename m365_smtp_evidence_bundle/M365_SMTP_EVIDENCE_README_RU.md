# Microsoft 365 SMTP: диагностический отчёт для поддержки

Этот пакет работает независимо от Maintenance Portal и Zabbix.

## Запуск

Перенесите `m365_direct_send_evidence.py` на `ml2zbx01` и выполните:

```bash
python3 m365_direct_send_evidence.py
```

Введите **реальные локальные значения**: MX организации Microsoft 365, адрес отправителя, адрес получателя, FQDN клиента для EHLO. Публичный NAT IP можно оставить пустым, если он неизвестен. Скрипт попросит `YES` перед отправкой **одного** письма.

При необходимости изменить тайм-аут:

```bash
python3 m365_direct_send_evidence.py --timeout 30
```

STARTTLS включается автоматически, если его предлагает MX. `--no-starttls` пригодится только для диагностического сравнения. SMTP AUTH не используется.

## Отчёты

После завершения скрипт создаёт в `./m365-smtp-evidence/` два файла с приватными правами:

- `m365_evidence_<id>.txt` — человекочитаемый отчёт для Microsoft.
- `m365_evidence_<id>.json` — машинный журнал с точными временными метками каждой команды и SMTP-ответом.

Записи включают From, To, UTC и локальное время с UTC-offset, Message-ID, remote destination, IP сервера-источника внутри сети, публичный IP (если известен из ответа MX или указан вручную), SMTP-ответы и финальный статус попытки.

Права каталога `0700`, файлов `0600`. Отчёты содержат реальные почтовые адреса/IP, не выкладывайте их в публичный чат.

## Принципиальные ограничения

- При прямой отправке Python → MX Microsoft 365 локального почтового шлюза/очереди **нет**. Соответственно, `queue record` Postfix получить невозможно. Отчёт документирует SMTP submission session, а не подменяет журналы реального шлюза.
- Если ошибка случилась на `EHLO`, письмо не поступало в SMTP-очередь Microsoft: `MAIL FROM`, `RCPT TO` и `DATA` не выполнялись.
- Если `DATA` завершился ответом `250`, это подтверждает приём письма MX, но не доставку в ящик. Для финального статуса нужен Exchange Online Message Trace по Message-ID / Sender / Recipient / времени.
- Если на `DATA` был тайм-аут, финальный статус неизвестен: автоматического повтора скрипт не делает, чтобы исключить дубликаты.
- Если `EHLO` не ответил, публичный исходящий IP невозможно достоверно получить из самой SMTP-сессии. Тогда можно указать известный адрес NAT; он будет явно помечен как `operator-supplied`.
